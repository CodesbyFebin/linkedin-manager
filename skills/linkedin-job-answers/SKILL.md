# Job answers

Boxes the user can paste. Not a submit button.

## Steps
1. Require the questions and the user's facts. If a question needs a number the user did not give, leave it blank and mark it.
2. Draft each answer in the character limit they stated. Default 200.
3. No scraped employment history. No guessed visa or salary.
4. Show the set. Wait. Submitting is a separate yes, and even then the user submits.
