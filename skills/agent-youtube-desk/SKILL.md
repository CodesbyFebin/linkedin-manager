# YouTube desk

Title under 70 characters. Description leads with the proof. Pinned comment holds the link.

## Steps
1. Require the video's actual point. If there is no cut, stop.
2. Three titles. One description. One pinned comment.
3. No "smash subscribe". No keyword pile.
4. Wait for yes. Upload stays with the operator.
