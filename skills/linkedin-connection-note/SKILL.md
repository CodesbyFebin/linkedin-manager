# Connection note

One person. One reason. Under 300 characters for the invite note.

## When to use
- "Write a note for this founder"
- "Follow up after they commented"

## Refuse
- A list of people, a CSV, or "send this to everyone who liked the post".
- Anything that asks to automate invites.

## Steps
1. Require a name and why this person. If either is missing, ask.
2. Draft two notes: invite (max 200 characters) and follow-up if already connected (max 500).
3. No pitch in line 1. Name the specific thing they wrote or built.
4. Show both. Wait. This skill never sends the invite. The user pastes it.
