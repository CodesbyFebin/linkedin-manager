# Case receipt

A post that can survive a skeptic. Built for operators who ship systems.

## When to use
- "Write the post for this deploy"
- "Turn this incident note into a LinkedIn post"
- "Receipt, not a launch announcement"

## Steps
1. Require three fields: what changed, what broke or was risky, what evidence exists. If one is missing, ask. Do not fill it.
2. Shape: hook with the object, the constraint, the move, the evidence, the limit.
3. Length 900 to 1,300 characters. Hook inside 210.
4. Ban launch voice: excited, thrilled, proud to announce.
5. Show the draft and the missing-evidence list. Wait for post.

## Hard rules

Global voice rules: see root SKILL.md Voice rules.
- No emoji. No hashtag block.
- Name the system only if the user named it.
- If the evidence is a private log, paraphrase. Do not ask the user to paste secrets.
