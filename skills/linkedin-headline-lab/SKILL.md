# Headline lab

Five headlines. Each under 220 characters. Each carries a role and one proof.

## Steps
1. Require role and one proof. If the proof is missing, ask. Do not invent a metric.
2. Write five. No emoji. No "passionate". No pipe-character pile longer than three beats.
3. Mark the one that matches `../../references/voice-profile.md` if it is filled.
4. Do not publish. The user pastes the winner into LinkedIn.
