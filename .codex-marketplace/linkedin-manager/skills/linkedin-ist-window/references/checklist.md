# linkedin-ist-window

No invented numbers. No publish without post or yes.

## Paste format

Paste one row per post, using your own observed data:

```text
YYYY-MM-DD | HH:MM IST | comments in first 24 hours: <count>
```

For example, replace the date, time, and count placeholders with values from your own posts. This format example contains no performance data; do not treat it as a measured result.

## Default operator window

When you do not have your own timing data, use **Tue-Thu, 08:30-10:30 IST** as a default operator window only. It is not a measured peak or a reach promise.
