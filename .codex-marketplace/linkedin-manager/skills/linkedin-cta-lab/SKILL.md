# CTA lab

The close is one job. Not a menu.

## When to use
- "The draft is fine, the ending is soft"
- "Give me three CTAs"

## Steps
1. Read the draft. State the single job: comment, save, or profile visit.
2. Write three closes under 25 words. One question, one specific ask, one no-ask stop.
3. Mark which one matches the voice profile if it is filled.
4. Do not publish. Hand the chosen line back to the user to paste into the draft, then `linkedin-humanizer` if they want a full audit.
