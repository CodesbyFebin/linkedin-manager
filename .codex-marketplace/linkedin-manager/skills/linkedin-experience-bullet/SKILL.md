# Experience bullets

Four lines. Each is a verb, an object, and a result the user stated.

## Steps
1. Require the role and the raw notes. Do not import numbers from memory.
2. Write four bullets under 200 characters each. No "responsible for".
3. Flag any result that was not in the notes.
4. Do not publish. Profile edits are pasted by the user.
