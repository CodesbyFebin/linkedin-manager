# Event note

A note about a thing on a calendar. Not a countdown.

## Steps
1. Require name, date, and what the room will get. City is optional.
2. Draft 700 to 1,100 characters. One ask: come, or read the notes after.
3. No "few seats left" unless the user states a real cap.
4. Gate it. Link in the first comment via `linkedin-first-comment`.
