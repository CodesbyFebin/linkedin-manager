# Feature picker

Three links the user already has. No new landing page.

## Steps
1. Require the list of shipped URLs or repo names. If the list is empty, ask.
2. Pick three. For each: title under 60 characters, one-line why, which audience it serves.
3. Refuse placeholders and "coming soon".
4. Do not publish. The user pins them.
