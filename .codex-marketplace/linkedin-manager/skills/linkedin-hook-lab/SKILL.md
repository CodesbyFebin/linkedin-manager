# Hook lab

Five openings. One claim. Nothing else.

## Steps
1. Lock the claim in one sentence. Ask if it is vague.
2. Write five hooks, each under 210 characters, each a different shape: number, object, failure, constraint, question.
3. Score each for filler and em dashes. Drop any that fail.
4. Do not draft the body unless asked. Hand the winner to `linkedin-post-writer`.
